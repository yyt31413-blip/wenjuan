问卷仍保留 42 道原始题目和照片。前 41 题必答，不选时无法前进；原问卷标注“选答”的 D01 可空白提交。页面不显示跳过按钮，服务端拒绝其他41题的缺题或空答案。B 类题原有的 X 选项可以表达“无法判断”，不计入 1—5 分值。参与者仍可随时停止填写。

管理员后台保留真实 D1 汇总统计及 PNG 图表下载。后台接口只向浏览器提供总览、倾向统计及 C01—C06 选项汇总，不返回最新提交摘要、复核编号、原始答卷或自由填写内容。多选题和倾向指标的饼图按各自有效分母单独展示。Excel/CSV 按钮、服务端下载接口、表格构建代码及相关依赖已移除；旧下载地址返回 404。

D1 集成测试仍覆盖并发重复提交只保留一份、磁盘持久化、505 条稳定分页、真实接口保存、管理员登录/撤销/过期/密钥轮换、限流及汇总数据读取。浏览器测试覆盖完整 42 题作答、提交失败保留草稿、真实 D1 写入、后台汇总、PNG 导出、移动端布局和退出后的权限撤销。

本地使用 Miniflare/workerd 的独立测试数据库，不影响正常预览的 .wrangler/state 数据。正式 D1 绑定、线上密钥和域名需在后续发布步骤配置。Cloudflare 免费 Workers 的 CPU 配额仍需上线实测；密码校验及服务端渲染可能超出额度。
